## 两家说的 CN2 GIA，根本不是同一条线

CN2 GIA 指的是中国电信的精品骨干网（AS4809），流量走这条线可以绕开普通 163 骨干网的拥堵节点，延迟更低，晚高峰更稳。麻烦在于，这条线只覆盖电信，而你和你的网站访客未必都用电信。

搬瓦工的解法是把三家运营商全部拉上精品线：电信走 CN2 GIA，移动走 CMIN2，联通走优化骨干，去程和回程都不含糊。不管什么时候做路由追踪，都能看到电信 59.43 开头的骨干节点，业内常把这套配置简称“三网 GIA”。

HostDare 的思路是把有限的预算花在刀刃上：回程对电信用户走 CN2 GIA，联通、移动的回程分别走 AS9929 和 CMIN2 这类优化通道，但去程三家全是普通直连。网络一拥堵，去程和优化通道的衔接处就会掉链子——后面实测数据里联通用户的延迟和丢包明显吃亏，根源就在这。

所以买之前先确认一件事：你自己和访客主要用什么宽带。这一条比两家的任何宣传都重要。
